# Space

一个基于 Godot 4 的 3D 太空飞行模拟程序。在真实的太阳系尺度下自由飞行，体验宇宙的浩瀚与孤独。

## 核心特性

- **自由飞行**：在 3D 太空中无拘无束地穿梭，WASD + 鼠标控制视角
- **真实比例**：星球大小与轨道距离基于真实天文数据
- **可调比例尺**：支持调整星球间距的缩放倍数，在"真实但空旷"和"紧凑可玩"之间自由切换

## 运行方式

用 Godot 4.x 打开 `project.godot`，点击运行即可。

## 控制

| 按键 | 动作 |
|------|------|
| WASD | 移动 |
| 鼠标 | 视角 |
| 滚轮 | 增加/减少移动速 |
| SHIFT | 加速 |
| ESC | 唤出鼠标 |
